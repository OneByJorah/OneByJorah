## What I build

- **AI agent infrastructure** — hub-and-satellite agent systems: LiteLLM routing, Honcho persistent memory, Qdrant vector storage, Telegram approval loops. See [StackForge](https://github.com/OneByJorah/StackForge), [OpsCenter](https://github.com/OneByJorah/OpsCenter), [NexusCore](https://github.com/OneByJorah/NexusCore).
- **Network and enterprise ops tooling** — AD replication monitoring, NOC dashboards, NVR dashboards, Pi routers, and helpdesk systems. See [SentryView](https://github.com/OneByJorah/SentryView), [PiRoute](https://github.com/OneByJorah/PiRoute), [DirWatch](https://github.com/OneByJorah/DirWatch), [ConfigVault](https://github.com/OneByJorah/ConfigVault).
- **MSP utilities** — Windows provisioning, self-service AD password reset, and helpdesk automation. See [MSPEngine](https://github.com/OneByJorah/MSPEngine), [AegisPass](https://github.com/OneByJorah/AegisPass), [CommandDesk](https://github.com/OneByJorah/CommandDesk).
